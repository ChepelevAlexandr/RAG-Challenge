# RAG-Challenge

Репозиторий содержит решение домашнего задания **RAG-Challenge**  
(моделирование Enterprise Retrieval-Augmented Generation системы).

Работа выполнена в рамках учебного задания и предназначена
для демонстрации кода и подхода к построению RAG-системы.

---

## Постановка задачи

Необходимо реализовать систему, которая:

1. Извлекает текст из PDF-документов.
2. Индексирует полученный текст.
3. Находит релевантные фрагменты под заданные вопросы.
4. Формирует ответы.
5. Автоматически формирует submission-файл в требуемом формате.

Генерация ответов без retrieval не используется.

---

## Описание решения

Реализована классическая RAG-схема:

- **Извлечение текста**  
  Используется библиотека PyMuPDF для чтения PDF-документов.

- **Поиск и индексация**  
  Применяется гибридный retrieval:
  - BM25
  - TF-IDF (word и char n-граммы)

- **Формирование ответов**  
  - rule-based извлечение числовых и логических значений,
  - при наличии ключа возможно использование GigaChat API,
  - каждый ответ сопровождается ссылками на страницы источников.

- **Генерация submission-файла**  
  Формирование JSON-файла происходит автоматически без ручных правок.

## Установка и запуск

### 1. Создание виртуального окружения
```bash
python -m venv .venv


Активация:

Windows:

.venv\Scripts\activate


Linux / macOS:

source .venv/bin/activate

2. Установка зависимостей
pip install -r requirements.txt

3. Сборка индекса
python main.py build-index --data-dir ./data --out-dir ./index

4. Генерация submission-файла
python main.py make-submission \
  --index-dir ./index \
  --questions ./data/questions.json \
  --out ./submission_name.json \
  --team-email your_email@example.com \
  --submission-name 

Примечания

Папка index/ и submission-файлы не хранятся в репозитории.

API-ключи передаются через переменные окружения.

Репозиторий предназначен для проверки кода, а не для распространения данных.
